Search Indexes
==============

Opencast uses OpenSearch both as a cache and as a fast way to perform full text searches on metadata.

A separate OpenSearch installation is required since Opencast version 9.0. Opencast requires OpenSearch 3.x.

Elasticsearch was previously supported as an alternative to OpenSearch, but that support has been dropped as of
Opencast 21.
