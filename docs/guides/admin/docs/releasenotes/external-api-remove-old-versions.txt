The External API no longer supports the API versions 1.0.0 to 1.10.0. Following the
[External API deprecation policy](https://docs.opencast.org/develop/developer/participate/proposal-log/#external-api-deprecation-policy),
an API version is supported for two Opencast releases after its successor was released. All of these versions are past
that point. The supported versions are now 1.11.0, 1.12.0 and 1.13.0.

Clients that explicitly request one of the removed versions in their `Accept` header (e.g.
`Accept: application/v1.10.0+json`) will now get a `406 Not Acceptable` response. Clients sending `application/json`
or no version are not affected and keep getting the current version.
