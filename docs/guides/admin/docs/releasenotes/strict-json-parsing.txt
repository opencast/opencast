Opencast replaced the json-simple library with Gson and now parses JSON strictly according to the JSON
specification. json-simple was more forgiving and accepted some malformed input, which is now rejected. This affects
all REST endpoints receiving JSON, including the External API, as well as JSON read from external tools and
services.

In particular, the following is no longer accepted:

- Unescaped control characters inside strings, like a literal line break or tab. These have to be escaped as `\n`,
  `\t`, etc.
- Trailing or duplicate commas in arrays or objects, like `[1,]`, `[1,,2]` or `{"a": 1,}`.

Requests containing such input will now fail, usually with a `400 Bad Request`. JSON generated by a proper JSON
library is not affected. Only clients building JSON by hand, e.g. through string concatenation, might need to be
fixed. [#7944](https://github.com/opencast/opencast/pull/7944)
